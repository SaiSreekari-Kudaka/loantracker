# 🌿 TribalEase — Loan Tracking & Financial Assistance Platform

A multilingual, voice-enabled web application designed to help users **calculate, track, and compare loans** while making financial information easier to understand.

## ✨ Features

- 🧮 EMI and interest calculation
- 📊 Loan amortization and financial charts
- 📋 Track and manage multiple loans
- 💳 Record loan payments
- ⚖️ Compare different loan options
- 🎙️ Voice input and text-to-speech support
- 🌐 Multilingual support for **English, Telugu, and Hindi**
- 📄 Export financial information as PDF
- 🌙 Light and dark mode

## 🛠️ Tech Stack

- **HTML5**
- **JavaScript**
- **Tailwind CSS**
- **Chart.js**
- **jsPDF**
- **Tesseract.js**
- **Web Speech API**
- **Browser localStorage**

## 📂 Project Structure

```text
loantracker/

├── index.html    # Main application interface
└── app.js        # Application logic and features
```

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/SaiSreekari-Kudaka/loantracker.git
cd loantracker
```

Open `index.html` in your browser.

For the best experience, run the project using a local development server such as **Live Server**.

## 💾 Data Storage

Loan data and user preferences are stored locally using **browser localStorage**. Data is stored on the user's device and is not synchronized across devices.
